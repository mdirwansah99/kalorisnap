Keselamatan

Password ni penghadang ringkas (client-side). Ia menghalang orang yang pinjam phone, bukan hacker. Jangan simpan gambar sensitif.

Sambung dari phone (GitHub Pages)
  1. Buka dashboard 9Router: http://localhost:20128/dashboard
  2. Pergi ke Tunnel → Enable. Kau akan dapat URL https://…
  3. Copy URL tu, tambah /v1 di hujung, tampal dalam Endpoint di atas.
  4. Masukkan API key 9Router kau, tekan Uji sambungan.

Sebab: app di GitHub Pages guna https://. Browser blok request ke http://localhost atau IP LAN (mixed content + Private Network Access). Tunnel https selesaikan masalah ni.
